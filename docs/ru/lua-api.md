# Справочник Lua API

Всё, до чего может дотянуться скрипт, находится в глобальной таблице `mf` и в
библиотеках, подключаемых через `require("mf.…")`. Язык — Lua 5.2 с `string`, `table`,
`math`, `coroutine` и `bit32`. Из `os` есть только `os.time()`, `os.date()` и `os.clock()`;
нет `io` и нет файловой системы.

Тот же API на JavaScript описан в [справочнике JavaScript API](js-api.md); короткие готовые
примеры собраны в [рецептах](cookbook.md).

## Общие правила

- Вызовы, которым нужно разрешение или которые могут не удаться по внешним причинам,
  не бросают ошибку, а возвращают `nil` и сообщение: `local value, err = mf.http{…}`.
- Вызовы с ошибкой программиста (не тот тип аргумента, некорректный текст JSON) бросают
  ошибку Lua. Неперехваченная ошибка останавливает модуль.
- Строки — это строки байтов. Тела `mf.http` и сохранённые файлы могут быть двоичными.

## Сведения о модуле

| Имя | Значение |
|---|---|
| `mf.id` | `id` из манифеста |
| `mf.name` | `name` из манифеста |
| `mf.version` | `version` из манифеста |

## Вывод и время

| Вызов | Описание |
|---|---|
| `mf.log(...)` | Пишет строку в вывод модуля. Аргументы соединяются табуляцией |
| `print(...)` | То же, что `mf.log` |
| `mf.sleep(секунды)` | Приостанавливает скрипт. Допустимы дробные значения |
| `mf.time()` | Секунды с 1970-01-01 UTC, с дробной частью |
| `mf.date([формат [, время]])` | Момент `время` (по умолчанию — сейчас) текстом |
| `os.time()`, `os.date(...)`, `os.clock()` | Целые секунды; то же, что `mf.date`; секунды равномерных часов для замера длительности |

`mf.date` понимает обычные директивы `strftime`: `%Y %y %m %d %H %M %S %j %a %A %b %B %p %Z
%z %%`. Используется часовой пояс устройства; чтобы получить UTC, начните формат с `!`. Без
формата результат выглядит так: `2026-03-01 14:05:09`.

```lua
mf.date("%d.%m.%Y %H:%M")          -- 01.03.2026 14:05
mf.date("!%Y-%m-%dT%H:%M:%SZ")     -- 2026-03-01T11:05:09Z
local t = mf.date("*t")            -- { year, month, day, hour, min, sec, wday, yday }
if t.wday == 1 then mf.log("воскресенье") end
```

## Разрешения

Приложение спрашивает у пользователя заявленные разрешения перед запуском модуля,
поэтому большинству скриптов эти вызовы не нужны.

| Вызов | Возвращает |
|---|---|
| `mf.granted(разрешение [, цель])` | `true` или `false`, не спрашивая пользователя |
| `mf.request(разрешение, причина [, цель])` | `true` либо `false` и причину. Если разрешения нет, показывает диалог и ждёт |

Причины, которые возвращает `mf.request`:

| Причина | Смысл |
|---|---|
| `NOT_DECLARED` | Разрешения нет в манифесте. Пользователя не спрашивают |
| `USER_DENIED` | Пользователь отказал. Позже можно спросить снова |
| `MODULE_NOT_ENABLED` | Модуль отключён |
| `TARGET_REQUIRED`, `TARGET_NOT_AUTHORIZED` | Только для разрешений, действующих против названной цели |
| `UNKNOWN_CAPABILITY` | Разрешения с таким названием не существует |

## Сеть — `NETWORK_OUTBOUND`

### `mf.http(запрос)`

```lua
local response, err = mf.http{
    url = "https://api.example.com/items",
    method = "POST",                                   -- по умолчанию "GET"
    headers = { ["Content-Type"] = "application/json" },
    body = mf.json.encode({ name = "x" }),
    redirects = 5,                                     -- по умолчанию 5; 0 вернёт ответ 3xx
}
if response then
    mf.log(response.status, #response.body, response.headers["content-type"])
end
```

| Поле результата | Смысл |
|---|---|
| `status` | Код состояния HTTP |
| `body` | Тело ответа строкой, не больше 8 МБ |
| `headers` | Таблица заголовков ответа; имена строчными буквами |
| `url` | Адрес, с которого пришёл ответ, после перенаправлений |

Вместо `body` запрос может нести форму или файлы; метод тогда по умолчанию `POST`.

```lua
-- application/x-www-form-urlencoded
mf.http{ url = "https://example.com/login", form = { user = "me", code = "1234" } }

-- multipart/form-data: поля формы и файлы
mf.http{
    url = "https://example.com/upload",
    form = { caption = "Отчёт" },
    files = {
        document = { filename = "report.txt", type = "text/plain", content = text },
    },
}
```

Файл — это таблица с `content` и, по желанию, `filename`, `type` и `field`; ключ в `files`
служит именем поля, если не задано `field`.

Что нужно знать:

- Только адреса `http://` и `https://` в публичном интернете. Сам телефон и локальная
  сеть недоступны: `destination is not a public internet address`.
- Сертификаты HTTPS проверяет хост. Плохой сертификат — это ошибка.
- Хост переходит по перенаправлениям: до пяти раз (не больше 10 через `redirects`).
  Заголовки `Authorization` и `Cookie` на другой хост не пересылаются.
- Один запрос на соединение. Запрос с долгим ожиданием просто ждёт сервер.
- Каждый запрос записывается в журнал аудита пользователя с именем хоста и портом.
- Одновременно может быть открыто не больше 16 соединений.

### `mf.connect(хост, порт [, параметры])` — сырое TCP-соединение

```lua
local conn = assert(mf.connect("irc.example.org", 6697, { tls = true }))
conn:write("NICK bot\r\n")
local line, err = conn:read_line(30)        -- nil, "timeout", если за 30 с ничего не пришло
conn:close()
```

| Вызов | Возвращает |
|---|---|
| `conn:read([макс [, таймаут]])` | То, что уже пришло, не больше `макс` байт (по умолчанию 16384) |
| `conn:read_exactly(сколько [, таймаут])` | Ровно `сколько` байт |
| `conn:read_line([таймаут])` | Одну строку без перевода строки |
| `conn:write(данные)` | `true` |
| `conn:close()` | |

Чтение ждёт, пока придут данные. С `таймаутом` в секундах оно вернёт `nil, "timeout"`, если
вовремя ничего не пришло; `nil, "closed"` значит, что другая сторона закрыла соединение.

### `mf.websocket(адрес [, заголовки])`

```lua
local ws = assert(mf.websocket("wss://stream.example.com/feed"))
ws:send(mf.json.encode({ subscribe = "news" }))
while true do
    local message, info = ws:receive(60)
    if message then
        mf.log(message)
    elseif info == "timeout" then
        ws:ping()                            -- минуту тишина: проверяем связь
    else
        break                                -- закрыто
    end
end
```

| Вызов | Возвращает |
|---|---|
| `ws:send(текст)` | `true`. Отправляет текстовое сообщение |
| `ws:send_binary(данные)` | `true`. Отправляет двоичное сообщение |
| `ws:receive([таймаут])` | Сообщение и `true` для текста, `false` для двоичного; `nil, "timeout"`; `nil, "closed"` |
| `ws:ping()` | `true` |
| `ws:close()` | |

На пинги сервера ответ отправляется сам, а сообщения из нескольких фрагментов приходят
целиком. Работают и `ws://`, и `wss://`. Правила те же, что у `mf.http`: только публичные
адреса, сертификаты проверяются, каждое соединение попадает в журнал аудита.

## Хранилище — `FILE_SANDBOXED`

Файлы модуля: зашифрованы на устройстве и удаляются вместе с модулем.

| Вызов | Возвращает |
|---|---|
| `mf.storage.read(путь)` | Содержимое либо `nil`, если файла нет |
| `mf.storage.write(путь, данные)` | `true`. Создаёт или заменяет файл |
| `mf.storage.delete(путь)` | `true`, если файл был удалён, иначе `false` |
| `mf.storage.list()` | Таблицу всех путей по алфавиту |

Пути относительные, части разделяются `/`, например `cache/page.html`. В частях допустимы
латинские буквы, цифры и `_ . @ + -`; `..` запрещено. Один файл — не больше 512 КБ, у
модуля — не больше 64 МБ в 2000 файлах.

Отсутствующий файл и отказ в вызове оба дают `nil`, поэтому, когда разница важна,
смотрите второй результат: `local data, err = mf.storage.read("x")`.

## Уведомления — `NOTIFICATIONS`

`mf.notify(заголовок [, текст])` возвращает `true` либо `nil` и сообщение.

В уведомлении стоит имя модуля — его добавляет приложение. У модуля одно уведомление:
новое заменяет предыдущее. Заголовок обрезается до 80 символов, текст — до 1000.

## Вопросы пользователю

`mf.ask(вопрос [, секрет])` показывает диалог и ждёт. Возвращает введённый текст либо
`nil`, если пользователь закрыл диалог. Чтобы скрыть вводимый текст, передайте вторым
аргументом `true`: `mf.ask("Токен", true)`.

Разрешение не требуется. В диалоге указано имя модуля и сказано, куда уйдёт ответ. Вопрос
обрезается до 500 символов.

## JSON и URL

| Вызов | Описание |
|---|---|
| `mf.json.decode(текст)` | Значение Lua из текста JSON. На некорректном JSON бросает ошибку — для чужих данных оборачивайте в `pcall` |
| `mf.json.encode(значение)` | Текст JSON из значения Lua |
| `mf.urlencode(текст)` | Кодирует текст для подстановки в URL; пробел превращается в `%20` |

Разбор: объекты и массивы становятся таблицами (массивы с 1), `null` становится `nil`,
то есть ключа со значением `null` в таблице не будет.

Запись: таблица, ключи которой — ровно `1..n`, становится массивом, любая другая —
объектом. Пустая таблица превращается в `{}`. Целые числа пишутся без дробной части.
Функции и таблицы с вложенностью глубже 64 уровней записать нельзя.

## Службы устройства — приложения, экран, камера

Скрипты могут пользоваться самим телефоном: открывать приложения, нажимать в них кнопки,
делать фотографии. Это часть ModuForge, требующая наибольшей осторожности, поэтому каждая
служба — отдельное разрешение, которое пользователь видит простыми словами до запуска модуля:

| Таблица | Разрешение | Что делает |
|---|---|---|
| `mf.apps` | `LAUNCH_APPS` | Перечислять, открывать и открывать ссылки в приложениях телефона |
| `mf.screen` | `SCREEN_CONTROL` | Касаться экрана и читать его в любых приложениях |
| `mf.camera` | `CAMERA` | Делать фотографии камерами |

Что пользователь получает взамен:

- Уведомление — «*модуль* управляет экраном» или «…использует камеру», пока модуль этим
  пользуется, и собственный индикатор камеры Android во время снимка.
- Каждый вызов, который что-то делает (касание, запуск, снимок), — в журнале аудита; чтение
  экрана — раз в минуту. То, что модуль вводит, в журнал не копируется.
- `mf.screen` работает, только пока пользователь держит включённой службу специальных
  возможностей ModuForge в настройках системы, и прекращается, когда он её выключает.

Открытие другого приложения уводит ModuForge с экрана, а модуль, который не умеет работать в
фоне, хост останавливает. Поэтому скрипту, который использует `mf.apps` или `mf.screen`,
редактор сам включает `BACKGROUND_EXECUTION`; в упакованном модуле объявите его сами.

Каждый вызов принимает аргументы **по порядку** или **одной таблицей**:
`mf.screen.tap(100, 200)` и `mf.screen.tap{ x = 100, y = 200 }` — одно и то же. Неудавшийся
вызов возвращает `nil` и причину, как и остальные службы.

### `mf.apps`

| Вызов | Возвращает |
|---|---|
| `mf.apps.list()` | Таблицу `{ package, name }` приложений со значком, по названию |
| `mf.apps.launch(app)` | `{ ok = true, package }`. `app` — имя пакета или название, как в лаунчере (сначала точное совпадение, потом часть названия) |
| `mf.apps.open(url)` | Открывает ссылку в приложении, которое её обрабатывает. `http`, `https`, `mailto`, `geo`; `tel` лишь набирает номер |
| `mf.apps.installed(package)` | `true` или `false` |

Сам ModuForge так запустить нельзя.

### `mf.screen`

Координаты — пиксели экрана в его нынешнем положении (поворот учитывается). Положение кнопок
лучше находить через `mf.screen.find`, а не угадывать.

| Вызов | Описание |
|---|---|
| `mf.screen.info()` | `{ width, height, package, enabled }` — размер, приложение сверху, включена ли служба |
| `mf.screen.tap(x, y [, ms])` | Касание; `ms` — сколько держится палец (по умолчанию 50) |
| `mf.screen.press(x, y [, ms])` | Долгое нажатие (по умолчанию 700 мс) |
| `mf.screen.swipe(x1, y1, x2, y2 [, ms])` | Смахивание (по умолчанию 300 мс) |
| `mf.screen.back()`, `home()`, `recents()`, `notifications()` | Системные кнопки и шторка уведомлений |
| `mf.screen.texts()` | Всё, что можно прочитать на экране: таблица `{ text, desc, id, x, y, bounds, clickable }` |
| `mf.screen.find(text)` | Элементы, у которых текст, описание или id содержит `text`; точные совпадения первыми |
| `mf.screen.click(text)` | Нажимает элемент с надписью `text` (или нажимаемый вокруг него) |
| `mf.screen.type(text)` | Вводит текст в поле, на котором фокус |
| `mf.screen.wait(text [, timeout])` | Ждёт (до 25 с, по умолчанию 10), пока что-то скажет `text`; элемент с `found = true` или `{ found = false }` |
| `mf.screen.event([timeout])` | Следующее событие на экране или `nil` |

`mf.screen.event` — способ среагировать на то, что пользователь делает в других приложениях. Он
возвращает `{ type = "click", package, text }`, когда нажали кнопку, `{ type = "window", package, title }`,
когда открылся экран, и `{ type = "notification", package, text }`, когда пришло уведомление.
Текст, введённый в поля, не сообщается никогда.

Некоторые экраны закрыты для модулей, что бы те ни просили: настройки системы, диалоги
разрешений и установщика и сам ModuForge — модуль не должен одобрять собственные разрешения.
Поля паролей не читаются и в них ничего не вводится. `back` и `home` работают всегда.

### `mf.camera`

| Вызов | Описание |
|---|---|
| `mf.camera.list()` | Объективы: таблица `{ lens = "back" или "front", id }` |
| `mf.camera.photo(path [, lens [, size [, quality [, flash]]]])` | Делает снимок и сохраняет его как `path` в хранилище модуля. Возвращает `{ ok, path, width, height, bytes }` |

`lens` — `"back"` (по умолчанию) или `"front"`; `size` — длинная сторона в пикселях (по
умолчанию 1280, не больше 2048); `quality` — качество JPEG (по умолчанию 80); `flash` —
`"off"` (по умолчанию), `"on"` или `"auto"`. Снимок сжимается, чтобы поместиться в файл
хранилища (512 КБ), поэтому модулю нужен `FILE_SANDBOXED`; прочитайте его через
`mf.storage.read` или отправьте дальше через `mf.http` — для этого нужен `NETWORK_OUTBOUND`,
так что пользователь видит, что модуль способен с ним сделать.

Android разрешает приложению пользоваться камерой, только пока оно видно или показывает
уведомление; учитывайте это в сценариях, которые снимают по таймеру. Камеру пользователь
разрешает один раз в **Настройки → Управление устройством**.

```lua
-- Открывает калькулятор, нажимает 7 + 8 = и читает ответ.
mf.apps.launch("Калькулятор")
mf.screen.wait("7", 8)
for _, key in ipairs({ "7", "+", "8", "=" }) do
    mf.screen.click(key)
    mf.sleep(0.4)
end
for _, item in ipairs(mf.screen.texts()) do
    if item.text:match("^%d+$") and item.y < 600 then mf.log("результат: " .. item.text) end
end
mf.screen.back()
```

## Хеши и кодировки

| Вызов | Возвращает |
|---|---|
| `mf.hash.sha256(данные [, raw])` | Хеш шестнадцатеричным текстом; сами байты, если `raw` равно `true`. Также `md5`, `sha1`, `sha512` |
| `mf.hmac.sha256(ключ, данные [, raw])` | HMAC, так же. Также `md5`, `sha1`, `sha512` |
| `mf.base64.encode(данные [, url])` | Текст Base64; `true` выбирает алфавит для URL без дополнения |
| `mf.base64.decode(текст)` | Байты. Принимаются оба алфавита |
| `mf.hex.encode(данные)`, `mf.hex.decode(текст)` | Шестнадцатеричный текст и обратно |
| `mf.random(сколько)` | `сколько` криптографически случайных байт, до 1024 |

```lua
local signature = mf.hmac.sha256(secret, timestamp .. body)
local nonce = mf.hex.encode(mf.random(16))
```

## Интерфейс

Скрипт может показать на экране модуля простой интерфейс и реагировать на него. Разрешение
не нужно. В упакованном модуле добавьте в манифест `"ui": "compose"`; модулям, написанным в
приложении, это ставится само.

```lua
local count = 0
local function draw()
    mf.ui.show({
        { type = "text", text = "Счётчик", style = "title" },
        { type = "text", text = "Значение: " .. count },
        { type = "row", children = {
            { type = "button", id = "minus", label = "−" },
            { type = "button", id = "plus", label = "+" },
        } },
        { type = "field", id = "note", label = "Заметка", value = "" },
    })
end

draw()
while true do
    local event = mf.ui.wait()               -- ждёт нажатия или ввода
    if event.type == "click" then
        count = count + (event.id == "plus" and 1 or -1)
        draw()
    elseif event.type == "text" then
        mf.log(event.id .. " = " .. event.value)
    end
end
```

| Вызов | Описание |
|---|---|
| `mf.ui.show(дерево)` | Заменяет показанное. Список — это колонка |
| `mf.ui.wait([таймаут])` | Следующее событие: `{ type = "click", id }` или `{ type = "text", id, value }`; `nil` через `таймаут` секунд |
| `mf.ui.clear()` | Убирает интерфейс |

| Элемент | Поля |
|---|---|
| `text` | `text`, `style`: `title`, `body` (по умолчанию), `caption`, `code`. Простая строка — тоже текст |
| `button` | `id`, `label`, `enabled` (по умолчанию `true`) |
| `field` | `id`, `label`, `value` |
| `row`, `column` | `children` |

## Библиотека `mf.config`

Настройки, которые лежат в хранилище модуля (`config.json`). Нужно `FILE_SANDBOXED`.

```lua
local config = require("mf.config")
local city = config.get("city", { ask = "Ваш город" })
config.set("last_run", mf.time())
config.forget("city")
```

| Вызов | Описание |
|---|---|
| `config.get(ключ [, параметры])` | Сохранённое значение. Если его нет — см. параметры |
| `config.set(ключ, значение)` | Сохраняет значение — любое, что записывается в JSON |
| `config.forget(ключ)` | Удаляет значение |

Параметры `get`:

| Параметр | Действие |
|---|---|
| `ask` | Вопрос пользователю. У ответа обрезаются пробелы; пустой ответ считается отсутствующим |
| `label` | Название значения на экране модуля. По умолчанию — текст вопроса |
| `secret` | Скрывать вводимое |
| `default` | Значение, если ничего не сохранено и ничего не ответили |
| `save = false` | Не сохранять спрошенное или подставленное значение |

**Настройки, которые пользователь может менять.** Каждое значение, прочитанное с `ask` или
`label`, появляется в карточке **Настройки** на экране модуля. Пользователь может изменить
его там в любой момент; работающий модуль перезапускается, чтобы подхватить изменение, а
если значение стереть, модуль спросит его снова или возьмёт значение по умолчанию. Поэтому
для настраиваемого модуля достаточно этого:

```lua
local token    = config.get("token", { ask = "Токен API", secret = true })
local interval = config.get("interval", { label = "Секунд между проверками", default = 300 })
```

Значения, записанные через `config.set` и не получившие названия (счётчики, последний
увиденный номер), — внутренние, они не показываются. Число или `true`/`false` остаётся
собой, когда пользователь его правит; всё, что введено в текстовое значение, приходит
строкой.

## Библиотека `mf.schedule`

```lua
local schedule = require("mf.schedule")
schedule.every(300, check)                               -- сейчас и затем каждые 5 минут
schedule.every(3600, report, { immediately = false })    -- первый раз через час
schedule.run()                                           -- не возвращается
```

| Вызов | Описание |
|---|---|
| `schedule.every(секунды, задача [, параметры])` | Регистрирует задачу |
| `schedule.run()` | Бесконечно выполняет задачи, чьё время пришло |
| `schedule.step()` | Выполняет их один раз; возвращает секунды до следующей |

Задача, бросившая ошибку, записывается в вывод и выполняется снова в свой следующий срок.
Задачи выполняются по очереди в потоке скрипта: медленная задача задерживает остальные.

## Библиотека `mf.telegram`

Каркас бота поверх Telegram Bot API. Нужны `NETWORK_OUTBOUND` и `FILE_SANDBOXED`.

```lua
local telegram = require("mf.telegram")
local bot = assert(telegram.bot())

bot:command("start", function(message, arguments)
    bot:reply(message, "Привет, " .. message.from.first_name, {
        reply_markup = telegram.keyboard({ { { "Да", "y" }, { "Нет", "n" } } }),
    })
end)

bot:on("text", function(message) bot:reply(message, message.text) end)

bot:on("callback", function(query)
    bot:call("answerCallbackQuery", { callback_query_id = query.id })
end)

local _, reason = bot:run()
mf.log("остановлен: " .. tostring(reason))
```

| Вызов | Описание |
|---|---|
| `telegram.bot([параметры])` | Создаёт бота. Если токена нет, возвращает `nil` и причину |
| `telegram.keyboard(ряды)` | Разметка кнопок под сообщением из рядов `{ текст, callback_data }` |
| `bot:command(имя, обработчик)` | `обработчик(message, arguments)` для `/имя`. Косая черта в начале `имя` необязательна |
| `bot:on(вид, обработчик)` | Виды — ниже |
| `bot:reply(message, текст [, доп])` | Отправляет текст в чат сообщения |
| `bot:send(chat_id, текст [, доп])` | Отправляет текст. `доп` добавляет любые поля `sendMessage` |
| `bot:call(метод [, параметры])` | Любой метод Bot API. Возвращает его результат либо `nil` и описание от Telegram |
| `bot:run()` | Проверяет токен и обслуживает обновления, пока модуль не остановят. Если Telegram отклонил токен, возвращает `nil` и причину |
| `bot:poll()` | Один раз забирает и обрабатывает обновления; возвращает их число либо `nil` и ошибку |

Параметры `telegram.bot`: `token` (иначе спрашивается у пользователя один раз и
сохраняется), `ask` (текст вопроса), `timeout` (секунды долгого опроса, по умолчанию 25).

Виды обработчиков для `bot:on`:

| Вид | Что получает | Когда вызывается |
|---|---|---|
| `"text"` | сообщение | Текстовое сообщение, не совпавшее ни с одной командой |
| `"message"` | сообщение | Любое другое сообщение, а также текст, если нет обработчика `"text"` |
| `"callback"` | callback query | Нажатие кнопки под сообщением |
| `"ready"` | сведения о боте | Один раз, после того как токен принят |

На что можно рассчитывать:

- Токен, который Telegram отклонил, забывается: при следующем запуске его спросят снова.
- Позиция в очереди обновлений сохраняется: перезапущенный бот не повторяет старые.
- Ошибка в обработчике пишется в вывод модуля и бота не останавливает.
- Если опрос не удался, бот ждёт 2, 4, 8 … до 60 секунд и пробует снова.

В пакет можно положить собственный `mf/telegram.lua`, `mf/config.lua` или
`mf/schedule.lua` — тогда вместо встроенного используется файл из пакета.
