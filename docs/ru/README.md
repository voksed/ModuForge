# ModuForge

ModuForge — приложение для Android, которое запускает чужие модули: ботов, скрипты,
небольшую автоматизацию. Каждый модуль работает в собственной песочнице, может делать
только то, что вы ему разрешили, а всё, что он делает в сети, записывается в журнал,
который можно прочитать.

Само приложение ничего не делает. Оно находит, проверяет, устанавливает, запускает,
изолирует и останавливает модули и решает, до чего каждый из них может дотянуться.

## Что работает сейчас

- Установка подписанных пакетов модулей (`.mfrg`): из файла, открытием файла из другого
  приложения или по ссылке на установку, которая заодно проверяет ключ автора.
- Модули на Lua и JavaScript и компилируемые модули на Kotlin, каждый в изолированном
  процессе.
- Написание модуля в приложении: редактор с подсветкой, подсказками и несколькими файлами.
- Сервисы хоста, закрытые разрешениями: интернет (HTTP, сырые соединения, WebSocket),
  зашифрованное хранилище, работа в фоне, уведомления, вопросы пользователю, простой
  интерфейс, который рисует приложение.
- Настройки модуля, которые пользователь может менять, и сохраняемый вывод модуля, которым
  можно поделиться.
- Автозапуск при включении телефона, обновление установленных модулей, журнал аудита.
- Обновление самого приложения из релизов на GitHub — по запросу.
- Для авторов: `mfrg run` выполняет модуль на компьютере, `mfrg push` отправляет его на
  телефон и показывает вывод, `mfrg pack` и `mfrg link` публикуют. Библиотеки для
  Telegram-ботов, настроек и расписаний на обоих языках.
- Темы: светлая, тёмная, цвета из обоев или свои, палитры, форма углов, размер текста.

## Чего пока нет

- Рантайма Python.
- Каталога модулей. Модули распространяются файлами и ссылками на установку.
- Сервисов за разрешениями `FILE_SHARED`, `CLIPBOARD`, `AI_INFERENCE`, `BOT_GATEWAY`,
  `DEVICE_INFO` и `LOCAL_NETWORK_SCAN`. Их можно заявить и выдать, но они ничего не
  открывают.
- Версии в Google Play. Play не допускает приложения, которые выполняют код, загруженный
  со стороны, поэтому ModuForge распространяется как APK.

## Ответственное использование

ModuForge — инструмент для автоматизации, обучения и авторизованного тестирования.
Используйте модули только против систем, которые принадлежат вам или которые вам явно
разрешено тестировать. В платформе нет эксплойтов и атакующих нагрузок, а модули для
отказа в обслуживании, массового таргетинга, кражи учётных данных и скрытой слежки
находятся за рамками проекта.
